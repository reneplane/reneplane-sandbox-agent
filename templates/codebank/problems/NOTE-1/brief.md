# Pinned notes don't stay on top

**Reported by:** Priya (support)

People pin a note so it stays at the top of their list, but since this morning's release pinned notes show up wherever their date puts them. A user pinned "Release checklist" and it's now halfway down the page.

**Expected:** pinned notes come first, newest first; then every other note, newest first.

**Actual:** the list is ordered by date only; pinning a note doesn't move it.

The frontend shows notes in the order the API returns them.
